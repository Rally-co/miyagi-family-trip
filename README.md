# 宮城 家族旅行 2026

GitHub Pages 公開用ファイルです。

## 公開手順
1. GitHubで無料アカウントを作成
2. 新しい Public repository を作成（例: miyagi-family-trip）
3. このフォルダ内の `index.html` をリポジトリ直下へアップロード
4. GitHubの `Settings` → `Pages`
5. `Build and deployment` の Source を `Deploy from a branch`
6. Branch を `main`、Folder を `/(root)` にして Save
7. 数分後に表示される公開URLを開く

## 注意
- 公開版からホテル予約番号は削除済みです。
- GitHub Pagesは公開サイトです。個人情報・予約番号・電話番号などは追加しないでください。
- カウントダウンとMIYAGI FAMILY QUESTはJavaScriptで動作します。
